# One-Line Office Jokes

A make.fun entry for the [One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc) competition: one single-line joke about office life, written by a small deterministic program.

## The entry

> The coffee machine broke on Monday; by Tuesday, HR had three resignation letters and one ransom note.

## How it works

`main.ts` (Node 22+, standard library only) writes exactly that one line to `/output/entry.txt` — no network, no clock, no randomness, so every run produces byte-identical output.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
